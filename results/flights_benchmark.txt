BTS Flights — Naive vs Tuned benchmark (flights_v2)
====================================================================================================
Date       : 2026-09-30
Host       : mv5jq8q8gv.asia-southeast1.gcp.clickhouse.cloud:9440  (ClickHouse 26.4.1)
Dataset    : flights — 51,642,689 rows (2017–2024)
Method     : clickhouse-benchmark, 3 warmup runs + 20 measured iterations per query;
             executed sequentially per pair (naive → tuned) under identical server conditions.
Stats      : p50 = median wall time per query (headline), p90 = tail.
             rows/bytes read per run and result rows are derived from the aggregate (RPS/QPS).
Fairness   : output equivalence of every pair verified before benchmarking (values, column
             names, row order — see diff check). Tuned queries read pre-aggregated tables;
             DDL/INSERT costs are NOT included (one-time build vs recurring read).
